# ScamTrapAlert 🛡️

ScamTrapAlert is an AI-powered Chrome Extension that helps users identify phishing attempts, scams, and suspicious messages across popular platforms such as WhatsApp Web, Gmail, and LinkedIn.

## Features

- Real-time scam detection
- Phishing message analysis
- AI-powered risk scoring
- WhatsApp Web monitoring
- Gmail email scanning
- LinkedIn message analysis
- Chrome Extension (Manifest V3)
- Fast API response
- Production-ready backend

## Tech Stack

### Frontend
- JavaScript
- HTML5
- CSS3
- Chrome Extension API
- Manifest V3

### Backend
- Node.js
- Express.js

### AI Integration
- LLM-based scam detection
- Risk classification engine

## How It Works

1. User opens WhatsApp Web, Gmail, or LinkedIn.
2. Extension extracts suspicious content.
3. Content is securely sent to the backend API.
4. AI model analyzes the message.
5. Risk score is generated.
6. User receives a warning if the content appears malicious.

## Key Features

### Scam Detection

Detects:
- Phishing attempts
- Fake job offers
- Financial scams
- Social engineering attacks
- Suspicious links

### Risk Scoring

Messages are categorized as:

- Low Risk
- Medium Risk
- High Risk

### Real-Time Analysis

Provides instant feedback while users browse supported platforms.


### Load Extension

1. Open Chrome
2. Navigate to chrome://extensions
3. Enable Developer Mode
4. Click Load Unpacked
5. Select the extension folder
